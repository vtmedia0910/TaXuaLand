# Known limitations and Phase 1 handoff

Phase 0 is a validated local release candidate and repository deliverable. It does not assert that a public production deployment, managed database, TLS/domain, storage/CDN account, legal review or field survey has occurred.

- DEM covers a representative bounded AOI/camera buffer, not the entire region. Source DSM includes vegetation/structures; 60 m normalization and finite LOD do not create survey detail. EGM2008-to-ellipsoid conversion is explicit and checked, but local absolute accuracy/control points remain UNKNOWN. Official administrative/cadastral boundary remains UNKNOWN.
- Public imagery is an explicitly labeled neutral grid; height colouring is terrain visualization, not aerial imagery or a hazard/slope assessment. The layer/provider architecture is present. OSM roads are a pinned attributed snapshot with UNKNOWN verification/access/safety. No routing, guaranteed reachability or travel-time model is implemented.
- No user-supplied real place workbook or surveyed control points were provided. Tests use authored synthetic fixtures, which are archived/disabled after relevant place QA; benchmark rows stay uncommitted staging. The public map can legitimately have no places until an administrator reviews and publishes real records. Never promote synthetic rows to populate a demo as real data.
- Mobile acceptance uses Chrome/CDP viewport, touch, network and CPU profiles, not a physical Android/iOS device fleet. Cold Cesium transfer is about 1.13 MiB gzip; constrained mobile is slower but measured within budget. CI validates clean install/build/PostGIS/security plus nine deterministic Core browser scenarios against a disposable LAND database. Release-heavy terrain/performance E2E still requires prepared local assets and credentials and remains separately evidenced; see [Core E2E](core-e2e.md).
- XLSX is limited to 8 MiB, 2,000 rows/sheet and bounded cells/ZIP expansion. Large regional ingestion is future work. UPDATE is an explicit complete replacement; field-by-field merge and automatic duplicate resolution are absent. VN-2000/local CRS requires a separately documented conversion into WGS84 before this import flow. Unsupported/missing transformation parameters must block, never be guessed.
- The private worker adapter needs a persistent Node service and volume. Production object-store/CDN promotion is documented, with a local filesystem adapter validated here. Credential federation/MFA, external telemetry collection, formal penetration testing and a production restoration/SLA plan require deployment-specific work.
- Windows Next/Webpack cache snapshot warnings were observed. Production minification uses a documented Terser workaround; all emitted client chunks are syntax-checked. Cesium's upstream demo token is removed at build time. Recheck both workarounds on upgrades.
- Local Git `.git` ACL became read-only during later milestones. Reviewed commits 14 onward were created on GitHub through the Git data API using non-force parent-checked updates; remote contents were verified. Local source files reflect the delivered work, but Git metadata may still show the old HEAD until the workspace ACL is restored. Do not reset/discard files to hide this state; fetch/reconcile against the remote after permissions are corrected.

## Handoff scope

Phase 1 may extend the regional terrain/imagery/road/village/POI base, camera presets, search/fly-to/share and measured spatial accuracy under a new approved specification. Preserve domain/application boundaries, per-observation source/verification/freshness, immutable geometry/provenance/releases, typed public DTOs, private imports and evidence-backed publication.

Start by obtaining authoritative AOI and survey/control-point evidence with declared horizontal/vertical datums, securing licensed imagery and durable deployment infrastructure, and measuring data quality before expanding coverage. Keep UNKNOWN until evidence supports a transition. Property marketplace, listings, sellers/CRM, leads/payments/contracts, valuation/suitability/viewshed engines and public AI were not built and are not authorized by this handoff.
