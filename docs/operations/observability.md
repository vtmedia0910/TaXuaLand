# Phase 0 diagnostics

Open `/admin/diagnostics` with a read-authorized LAND account. The page shows source status, licence and review dates, freshness, dataset releases/CRS/vertical datum, provider health and kill switch, and the latest 30 import batches. UNKNOWN dates or verification remain UNKNOWN. Provider credentials and payloads, workbook values, storage keys, and committed place IDs are excluded from operational summaries.

“Kiểm tra viewer” loads the lazy Cesium engine only on demand. Initialization, first rendered frame and first stable frame are separate metrics. Stable means two rendered frames after camera motion stops with current terrain tiles and data sources ready. These local measurements include asset processing after engine initialization, but exclude the initial page and lazy JavaScript download. Performance baseline navigation measurements cover the full path. The panel shows WebGL, terrain/road state, neutral-grid imagery status, release IDs, asset failures, client render failures and point-layer rebuild time. “Dừng kiểm tra viewer” destroys the viewer and aborts terrain requests. This is local diagnostics, not a remote tracking service.

Every API response has a server-generated `X-Correlation-ID`; error JSON contains the same value. Server stdout emits one JSON `http_request` event with method, route template, status, duration and allowlisted error category. Dynamic URL segments and all query strings are removed. Driver SQL/messages/details, request bodies, cookies and authorization headers are never included. A pool error emits `DATABASE_UNAVAILABLE`. Send these JSON events to the deployment log collector with restricted access and retention; aggregate latency and error rate there. Do not enable raw HTTP body capture.

Categories distinguish input rejection, authorization, concurrency/conflicts, rate limiting, database constraints/timeouts/unavailability and unexpected faults. Use the correlation ID with audit events to investigate a particular action. Import validation duration is persisted in milliseconds; summaries expose row states, duplicate-row counts, error codes/counts and atomic commit counts. No diagnostic action approves data or changes source/verification state.

Browser QA artifacts can contain authored fixture text and local test-account form state. `work/`, `test-results/` and Playwright reports are ignored/private; never publish them wholesale. Share only reviewed, redacted screenshots and aggregate measurements.
