# TÀ XÙA LAND

Independent spatial platform, Phase 0. Architecture authority: [specification](docs/PHASE_0_SPATIAL_FOUNDATION.md).

## Development

Use Node 24 LTS and pnpm 11.19.0. Run `pnpm install`, `pnpm check`, then `pnpm dev`.
Admin will live under `/admin` in the Next.js app; domain/application packages remain separate from routes.
No application credentials or databases are shared with other Tà Xùa products.

## Implementation status

See [milestones](docs/operations/implementation-status.md). Phase 0 is incomplete until every mandatory acceptance criterion is evidenced; passing a build alone is insufficient.
